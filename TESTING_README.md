# Тестирование компонентов Profile

## Установка зависимостей

Для запуска тестов необходимо установить следующие зависимости:

```bash
npm install --save-dev @testing-library/react @testing-library/jest-dom @testing-library/user-event jest jest-environment-jsdom @types/jest
```

## Структура тестов

Все тесты находятся в папке `src/components/profile/__tests__/`:

- `ProfileHeader.test.tsx` - Тесты для компонента ProfileHeader (логика аутентификации, logout)
- `ProfileContacts.test.tsx` - Тесты для компонента ProfileContacts (условное отображение Primary badge)
- `ProfileTransportInfo.test.tsx` - Тесты для компонента ProfileTransportInfo (условная логика byBus)
- `ProfileActions.test.tsx` - Тесты для компонента ProfileActions (базовый рендеринг и навигация)

## Запуск тестов

### Запустить все тесты один раз
```bash
npm test
```

### Запустить тесты в режиме watch (автоматический перезапуск)
```bash
npm run test:watch
```

### Запустить тесты с покрытием кода
```bash
npm run test:coverage
```

## Конфигурация

### jest.config.js
Основная конфигурация Jest для Next.js проекта с поддержкой:
- TypeScript и JSX
- Алиасов путей (@/*)
- Автоматических моков для next/navigation, next-intl, Firebase
- Покрытия кода

### jest.setup.js
Файл настройки с глобальными моками:
- @testing-library/jest-dom для дополнительных matchers
- next/navigation (useRouter, usePathname, useSearchParams)
- next-intl (useTranslations, useLocale)
- next/image
- Firebase auth (signOut, getAuth)
- global.fetch

## Советы по написанию тестов

1. **Тестируйте важную логику**, а не только рендеринг
2. **Используйте describe блоки** для группировки связанных тестов
3. **Мокайте внешние зависимости** (Firebase, API, навигация)
4. **Проверяйте условную логику** (if statements, ternary operators)
5. **Тестируйте обработку ошибок** и edge cases
6. **Используйте waitFor** для асинхронных операций
7. **Проверяйте пользовательские взаимодействия** (клики, ввод)
